# User REST API

A REST API for managing users with Express, MongoDB, and Mongoose.

## Routes

- `GET /api/users`
- `GET /api/users/:id`
- `POST /api/users`
- `PUT /api/users/:id`
- `DELETE /api/users/:id`

## Run

```bash
npm install
```

Copy `.env.example` to `.env`, then:

```bash
npm run dev
```
