# Full Stack To-Do Application

Connects a React frontend to an Express + MongoDB backend.

## Features

- Registration and login
- JWT authentication
- Protected React route
- Task create/read/update/delete
- Axios communication
- MongoDB persistence

## Run

```bash
npm install
npm run install:all
```

Copy `server/.env.example` to `server/.env`, configure MongoDB/JWT, then:

```bash
npm run dev
```
