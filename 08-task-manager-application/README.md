# Task Manager Application

Week 3 mini project: a complete task tracking web app with user login and task filtering.

## Features

- React frontend
- Express backend
- MongoDB storage
- Registration and login
- JWT-protected API
- Create/update/delete tasks
- Status filtering
- Priority levels
- Responsive layout

## Run

```bash
npm install
npm run install:all
```

Copy `server/.env.example` to `server/.env`, configure MongoDB/JWT, then:

```bash
npm run dev
```
